![C](https://img.shields.io/badge/c-%2300599C.svg?style=for-the-badge&logo=c&logoColor=white)

Author: Martijn Wallage

A project of the 42 Core Curriculum.

Score: 125%

## About

A program which recreates the pipe operation `|` in the Bash shell and writes the output in a file.

Usage:

`./pipex file1 cmd1 cmd2 file2`

## Bonus

Handle multiple pipes in succession. 

I recommend doing the bonus as preparation for <a href="https://github.com/MartijnWallage/42_minishell">minishell</a>.
